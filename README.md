# Baseball Analytics

R code behind my writing at https://henryjbelton.substack.com

## Projects
- **bat-speed/**: What drives bat speed? OLS on swing length, weight, age, height, zone height. [Read the post](https://henryjbelton.substack.com/p/what-drives-bat-speed)
- **hitter-aging/**: GAM age curves and regression to the mean for hitters. [Read the post](https://henryjbelton.substack.com/p/father-time-vs-hitters)
- **sun-altitude/**: Does sun altitude affect xwOBA at Rate Field? [Read the post](https://henryjbelton.substack.com/p/sunlight-and-stuff)

## Data
Data comes from Baseball Savant, FanGraphs, and baseballr. Raw files are not included, so see each folder for how to pull them.
